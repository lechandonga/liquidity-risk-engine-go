# 本地验证方法

全部验证均可离线完成，不依赖外部服务或凭据。

## 环境

- Go 1.25+（在 Go 1.26 上验证）
- race 检测需要 CGO 与 gcc（如 Linux 上的 build-essential）。

## 命令

```bash
# 1) 单元测试（-v 日志逐条打印“[业务:..][用例:..] PASS - 说明”）
go test -v -count=1 ./...

# 2) race 检测 + 反复运行（并发用例稳定性）
CGO_ENABLED=1 go test -race -count=20 ./...

# 3) 覆盖率
go test -coverprofile=cov.out ./...
go tool cover -func=cov.out

# 4) 静态检查
go vet ./...
gofmt -l .   # 应无输出

# 5) 端到端演示
go run ./cmd/lre
```

也可以直接 `make test / make race / make cover / make demo`。

## 测试覆盖的业务链路

| 业务 | 用例 |
| --- | --- |
| 脏数据与重复登记 | 缺字段、金额/期限非法、币种不符、未知产品、方向口径不符、摊还计划非法、HQLA 级别非法；整批原子拒绝；批内/跨批重复登记；`REGISTER` 与 `CORRECT` 区分 |
| 现金流分桶确定性 | 多产品合同展开的分桶结果不随登记顺序变化；任意时点净现金流查询 |
| 日历日确定性 | 非法日历日拒绝；加减天与 YYYY-MM-DD 序列化；空日期零值 |
| 情景版本与复现 | 参数越界/自相矛盾拒绝；未定义父情景拒绝；分层覆盖规则；父版本固定（子不被父新版本改写）；同名同版本不可变发布；旧版本结论原样复现；缺分层假设拒绝；生存期/LCR 计算 |
| 回填/冲正/重复回放 | 回填历史日期；同批次任意次数重复回放幂等不计数；冲正、重复冲正与二次冲正拒绝；对冲正再冲正（恢复）；本地 NDJSON 日志回放状态一致 |
| 并发读写一致性 | 8×60 批写入 + 重复回放 + 持续查询 + 同步计算 + 基于条件变量等待的异步计算；校验序号单调、快照自洽且不可变；`-race -count=20` 稳定通过，无 sleep |

说明：并发用例的同步原语是 `WaitGroup`、`channel` 与引擎内部 `sync.Cond`
（异步计算等待 `MinStateSeq`），没有任何基于 `time.Sleep` 的时序假设。
