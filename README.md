# 本地流动性风险计量与压力测试引擎（Go）

完全本地运行的流动性风险计量引擎：把头寸/合同数据按合同现金流与行为假设展开为
时间桶现金流阶梯，在带版本的压力情景下计算净现金流、LCR 与生存期，并在持续写入
（含回填、冲正、更正）的同时提供只基于完整时点状态的不可变快照。

无外部服务、无网络调用、无真实凭据；持久化（可选）仅使用本地 NDJSON 文件。

## 快速开始

```bash
make test      # 普通单测（日志含业务/用例覆盖情况）
make race      # race 检测下反复运行（需 CGO/gcc）
make demo      # go run ./cmd/lre 端到端演示
make cover     # 覆盖率报告
```

## 模块结构

| 包 | 职责 |
| --- | --- |
| `pkg/lre/domain` | 头寸、现金流、日期、情景、批次/事件等领域模型与逐笔校验、错误原因码 |
| `pkg/lre/ladder` | 合同现金流展开、同日同口径确定性合并、时间桶阶梯与任意时点净流查询 |
| `pkg/lre/scenario` | 情景发布/继承解析/分层覆盖、行为现金流展开、LCR/生存期指标 |
| `pkg/lre/engine` | 原子批次、幂等回放、回填/冲正/恢复、不可变状态与快照、异步计算、本地日志 |
| `cmd/lre` | 本地端到端演示 |
